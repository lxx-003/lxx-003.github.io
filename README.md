## 如何新增页面

1. 新建一个英文短名子目录，例如 `my-demo/`，把你的页面放进去并命名为 `index.html`；
2. 在根目录 `index.html` 中按需补充一条入口链接；
3. 提交并推送到 `main` 分支后，即可通过 `https://lxx-003.github.io/my-demo/` 访问。
