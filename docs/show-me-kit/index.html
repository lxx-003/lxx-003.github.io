06

人物与涂鸦 Character & Doodles

插画不是装饰，是语气。固定一个“黑发 + 蓝卫衣 + 猫脸电脑”的人物，再配一点蓝色笔画、黄色便签和手绘箭头，页面就活了。

黑发 · 蓝卫衣 猫脸电脑 三种表情复用

人物只换表情和手势：疑惑、思考、讲解。身体和电脑保持不变，读者会认人，也会认这套图。

左密右疏 虚线箭头 去掉无关枝叶

修剪树是“边界”的视觉隐喻：左边保留所有枝叶，右边只留刚好够用的部分。配套文案永远是“最小视图”。

组合的四条规矩

  1. 一屏只放一个主动作：要么一张大图，要么一组卡片。
  2. 每张卡片最多 1 处红色，其余信息用墨黑和灰。
  3. 黄色便签只放结论、提示、旁白，不要用来放正文。
  4. 图标统一粗描边 + 马卡龙填充，尺寸可以变，线宽比例不变。

这张小海报就是活例子：标题、下划、灯泡、便签、四个图标、乱线、箭头，全部来自前面的组件库。

复用提示

  1. 先定纸白和墨黑，再把蓝、黄、红作为强调色加进去；不要反过来先铺彩色。
  2. 字体不必完全一致：圆体 / 手写体 / 系统黑体都能用，关键是标题够粗、笔画够圆。
  3. 图标可以换：只要保持 64 视窗、粗描边、马卡龙填充，整套气质就不会散。
  4. 红色要克制：把它当荧光笔，不要当正文色。
